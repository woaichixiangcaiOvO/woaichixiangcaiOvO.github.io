# OvO · 个人作品网站

OvO 的个人作品展示网站源代码仓库，主要面向国内访客，用于展示产品设计、UI 与交互设计作品。

## 当前状态

- 已创建公开仓库，默认分支为 `main`。
- 本次仅初始化仓库与 GitHub Pages 发布设置，尚未开始正式页面、建模或交互开发。
- GitHub 已在仓库初始化时发布 README 说明页；正式作品网站完成并验证后，使用 GitHub Pages 更新发布。
- 自定义域名留待后续绑定，当前不设置 `CNAME`。

## 已确认方向

- 核心技术：Three.js + Rapier，在访客浏览器中运行。
- 桌面优先；双场景为太空工作室与 F1 赛道窗景。
- 首版作品：映遇、蹦动；支持中文与英文。
- 个人简介、联系方式及案例正文以作者确认可公开的实际资料为准。
- 配套框架、依赖版本、构建命令和最终资源目录在正式开发时确定。
