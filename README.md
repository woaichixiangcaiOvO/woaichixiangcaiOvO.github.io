# OvO · 个人作品网站

OvO 的个人作品集。桌面首页接入已确认的 3D 工作室，支持太空与赛道窗景。访客可以从电脑或放映机在同页阅读映遇和蹦动。

## 本地预览

在本仓库运行以下命令。

```sh
npm ci
npm run build
npm run preview
```

- [首页与工作室](http://127.0.0.1:4320/)
- [映遇独立分享页](http://127.0.0.1:4320/works/yingyu/)
- [蹦动独立分享页](http://127.0.0.1:4320/works/bounce/)

独立分享页可以直接阅读和刷新。「进入工作室」会在同一标签页开启 3D 全景。浏览器后退可返回分享页。站内关闭映遇后用浏览器前进，会恢复原先的正文位置和视频时间，视频保持暂停。

首页可用 `?scene=orbit` 或 `?scene=monza` 固定初始窗景，用于本地验收。预览服务只监听本机，默认端口为 4320。改动后重新运行 `npm run build` 并刷新页面。

已复测铅笔与上层书架、柜面和下层书本的接触，以及与桌面小本子相撞。铅笔和小本子均可在赛道版落到木地板表面。接触校正使用它们当前朝向下的实际碰撞轮廓。

## 源码与构建

- `site/` 保存首页、工作室代码、已选模型和媒体。
- `content/` 保存两份案例正文。构建时用同一份正文生成独立分享页和站内嵌入稿。
- `dist/` 是静态构建产物。已锁定的 Three.js 和 Rapier 随构建一起输出。

本仓库当前交付本地候选版。正式发布和自定义域名待作者安排。
